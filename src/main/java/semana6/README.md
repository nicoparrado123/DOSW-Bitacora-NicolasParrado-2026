# Semana 6

## Ejercicio - Sistema de notas equipo naranja

El ejercicio consiste en un programa que maneja las notas de un grupo de estudiantes divididos por equipos.

Con esa informacion el sistema puede hacer cosas como:

- Filtrar solo los estudiantes del equipo naranja
- Calcular el promedio general de todos los estudiantes
- Ver el promedio de cada estudiante por materia
- Saber quien es el mejor estudiante
- Ver cuantas materias reprobadas tiene cada equipo
- Sacar el top 3 de estudiantes con mas materias aprobadas
- Agrupar estudiantes segun como les esta yendo (bien, regular o en riesgo)
- Ver cual es la materia con mas reprobados
- Analizar como le fue al equipo naranja en cada materia
